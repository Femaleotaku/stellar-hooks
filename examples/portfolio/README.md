# Stellar Portfolio & Balance History Example

A responsive portfolio tracker example demonstrating `useFreighter` + `useStellarBalance` + `useStellarAccount` + `BalanceHistoryChart` using lightweight charting (`uPlot`).

## Features

- 👛 **Wallet Connection**: Connect via Freighter or supported browser extension
- 📊 **Balance History Visualization**: Interactive balance timeline across 24H, 7D, 30D, 90D, and 1Y intervals
- 💰 **Multi-Asset Portfolio**: Real-time breakdown of native XLM and trustline token holdings
- ⚡ **Lightweight & High-Performance**: Fast canvas/SVG rendering powered by `uPlot`

## Running Locally

```bash
cd examples/portfolio
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.
